AI Knowledge Assistant (LexGuard AI)

This project is a document-based AI assistant designed to help users interact with legal documents in a more intuitive way.
It allows users to upload documents, analyze their content, and ask questions through a conversational interface.

The system combines a backend for document processing and semantic search with a modern frontend for user interaction.

Features:
-Upload and process PDF documents
-Ask questions based on uploaded content
-Perform basic legal and risk analysis
-Retrieve context using semantic search
-Train a custom knowledge base
-Simple and responsive web interface

Core Components:
-Chat module for handling user queries
-Upload module for document ingestion
-Analysis module for extracting insights
-Vector storage for semantic retrieval
-Training script for building the knowledge base
-Technologies Used

Backend:
-Python
-FastAPI (or similar framework)
-Vector database (such as FAISS)

Frontend:
-React
-Vite
-JavaScript

Use Cases:
-Legal document review
-Contract analysis
-Document-based question answering
-Research assistance
